Important: This first alpha installer supports clean installations only; it will refuse to overwrite an existing FerretOS Launcher installation or retained updater state. The installer is not Authenticode-signed, so Windows may display a SmartScreen reputation warning. Never disable your security protection to install software.

The download includes no World of Warcraft game files. To play, you need your own compatible WoW 3.3.5a client, separate approval for the private FerretOS realm and Tailscale access. Updates are checked using the official signed release manifest.
